# 04 — RÈGLE DE COULEUR

Le portfolio ne doit surtout pas être entièrement violet ou entièrement rose.

Créer un équilibre visuel :

**Blanc = base**

**Mauve = identité principale**

**Rose = accent**

Le mauve et le rose doivent être utilisés avec intelligence.

Créer parfois des transitions visuelles très légères entre mauve et rose, mais **éviter les gros gradients criards**.

Les gradients, lorsqu'ils sont utilisés, doivent être subtils et premium.

Exemple d'ambiance :

**Mauve → Rose**

avec beaucoup de blanc autour.

# 14 — PROJET JOKKO 360°

Nom :

# JOKKO 360°

Slogan :

**Un scan. Tous vos services.**

Secteur :

**Hôtellerie — Restauration — Services numériques**

Présenter le projet comme une vraie étude de cas.

### Problème

Les clients d'un hôtel ou restaurant utilisent différents moyens pour demander des services, ce qui peut provoquer :

* attente ;
* oubli ;
* mauvaise communication ;
* manque de coordination.

### Solution

JOKKO 360° permet au client de scanner un QR Code présent dans la chambre ou sur la table afin d'accéder rapidement aux services disponibles.

Services :

* Room service
* Ménage
* Serviettes
* Signaler une panne
* Taxi
* Réception
* Activités

Créer des mockups :

* QR Code ;
* chambre d'hôtel ;
* table de restaurant ;
* téléphone ;
* interface mobile.

Créer une présentation premium du projet.
